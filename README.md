# megumi辞書

一个印尼语背词 App：单词四选一测验 + 间隔重复 + 词根关系网。

Flutter 写的 Android 应用，本地存储，不联网。

## 功能

- **单词记忆**：一个词一个词地记，四选一选中文释义
- **间隔重复**：答对推进记忆格（1 / 2 / 4 / 7 / 15 / 30 天），答错打回重来
- **分级词单**：基础词库分初级 / 中级 / 高级三册，另有自建词库分类
- **词根关系网**：点单词右侧的图标，看同一词根派生出的词按词缀排列对比
- **搜索**：词条搜索，结果同样带词根入口
- **数据备份**：导出 / 导入 JSON 备份

## 构建

```bash
flutter pub get
flutter build apk --release
```

需要 Flutter 3.35+、JDK 17、Android SDK 36。

## 词库数据

本仓库**不含**扫描词典的完整数据，`assets/dictionary.json` 只放了 40 条示例词，用于让项目能直接构建运行。

要使用完整词库，需要自己准备：

1. 把词典扫描成图片 / PDF
2. 用 PyMuPDF 渲染页面，RapidOCR 做 OCR，得到每页文本
3. 按 `工具脚本` 的思路解析成 `dictionary.json`（字段：`w` 单词、`g` 释义、`lvl` 级别、`pos` 词性、`ex` 例句、`exc` 例句翻译）

数据文件格式：

```json
{"w": "serta", "g": "以及，和，连同", "pos": "连", "lvl": 0, "p": 950}
```

`families.json`（词族）与 `affixes.json`（语素拆解）同理，缺失时 App 会退化为「只看得到人工整理的词族」。
